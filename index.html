How to add electrons safely to interfacial Pt6: measuring Q0 first, then setting Q = Q0 − Δn

GPAW CDFT fixed-geometry scan · updated 29 September 2026

Abstract. Extra electrons on Pt are imposed with GPAW CDFT by constraining the Pt6 net charge Q = Z − Ne. The only number that must be measured and then written into the input is the unconstrained charge Q0. Targets are then Q = Q0 − Δn. An incorrect Q0 (inconsistent CDFT weight) left residuals of ~17–54 e− already at Δn = 0 and mostly crashed; the corrected protocol gives λ(0) = 0 and a complete Δn = 0→2 scan for all six models.

What to put in the code after Q0 is measured

DO set the CDFT charges list to the target net charge on Pt6. DO NOT paste λ into the input — λ is optimized by CDFT, not a user parameter.

Qtarget = Q0 − Δn

Example: pristine vacuum, add 1 electron → charges = [34.598857 − 1.0] → charges = [33.598857]. 

# After q0.json is written for a given structure:
Q0 = 34.598857          # from work/

Use the same GPAW CDFT weight (default Rc/μ) for measuring Q0 and for the constrained run. Do not mix a hand-rolled weight with CDFT.

Failure versus success of Q0

Round 1 estimated Q0 with a homemade weight integral that did not match GPAW CDFT. At Δn = 0 the constraint residual was already ~17 e− (vacuum) or ~51–54 e− (H2O/KOH), so SCF mostly failed. Round 2 measures Q0 with CDFT itself (λ = 0 probe); residuals at Δn = 0 fall to ~10−4 e− and λ = 0.
